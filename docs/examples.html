Hello World

Your first Braw program.

import "stdinout.braw"
                    
fn main() -> int {
    print_string("Hello, world!\n");
    return 0;
}

Compile it using this command.

./brawc main.braw --assemble --link

Functions

How to declare and use functions.

fn times2(n: int) -> int {
    return n * 2;
}
You can also declare single line functions like this: 
fn times2(n: int) -> int: return n * 2;

While loops

let n = 0;

while (n < 10) {
    print_string("Hello, world!\n");
    n = n + 1;
}

You can also run do-while loops:

do while (n < 10) {
    print_string("Hello, world!\n");
    n = n + 1;
}

For loops

for (let i = 0; i < 10; i = i + 1):
    print_string("Hello, world!\n");

Macros

Macros in Braw are defined using the macro keyword and invoked using the $ symbol.

macro CONST: 5;

fn wow() -> void {
    let a: int = $CONST;
}

Macros can take parameters:

macro CONST(param): 5 + #param;

fn wow() -> void {
    let a: int = $CONST(5);
}

Parameter Kinds

Parameters can be:

  • Instructions: passed directly, expanded with #param
  • Values: passed as #"value", get assigned the value
  • Types: passed as #<int>, get the typename
  • Functions: passed as #fun(), get the function name

Parameters also have fields accessible with #param.field:

  • Types: #param=>memberName
  • Functions: #param=>returnType, #param.parameters

Macro Constructs

You can use the following constructs inside macros for compile-time logic:

  • $concat(a, b, ...) – concatenate values
  • $compare(a, b) – returns true if equal
  • $not(val) – boolean negation
  • $and(a, b) – boolean AND
  • $or(a, b) – boolean OR
  • $if(val) { ... } – includes body only if value is true
  • $foreach(v : value) { ... } – repeat body for each member in value

Full example

type MV {
    a: int;
    b: int;
}

macro GETTERS(type) {
    $foreach(var : #type) {
        fn $concat(#type, #"_get_", #var=>name)(v: #type) -> #var: return v.#var=>name;
    }
}

$GETTERS(#);

fn m_macro() -> int {
    let v: MV; v.a = 1; v.b = 1;
    return MV_get_a(v) + MV_get_b(v);
}
